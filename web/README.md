# Essence Network Functional App

This is an installable PWA-style multi-page web app. It works offline after being served once, stores demo editorial/contact data in browser localStorage, includes an admin demo, programme filters, EPG, search and a simulated live player.

Open index.html to browse. For PWA/service-worker installation, host the folder with any simple web server (for example VS Code Live Server or a normal web host).

For production: connect the existing Essence CMS API, real HLS/DASH stream, CDN, database, authentication, VOD storage and analytics.
